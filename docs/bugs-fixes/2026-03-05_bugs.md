## BUG-16: Bodyweight exercises show empty chart on ExerciseProgressScreen
**Status:** OPEN
**Priority:** P2 (medium)
**Reported:** 2026-03-05
**Screen:** ExerciseProgressScreen (`ExerciseProgressViewModel.kt`)
**Plan:** `2026-03-05_plan_pr-progress-charts.md` (item A.3)

### Problem
Bodyweight-only exercises (e.g., unweighted pull-ups, push-ups, bodyweight squats) produce no data points on the exercise progress chart. The chart shows the empty state ("No data yet") even though the user has completed sets for the exercise.

### Root Cause
`ExerciseProgressViewModel.findBestWeight()` at line 167-171 filters sets with `it.actualWeightKg != null` and takes the max. For bodyweight exercises where no external weight is used, `actualWeightKg` is either null or 0.0, causing the filter to exclude all sets or return 0.0 (which is not meaningful as a "best weight").

The max weight chart has no concept of substituting body weight from the user profile, so bodyweight exercises silently produce an empty chart.
